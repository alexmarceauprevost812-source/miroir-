      Caméra du téléphone → webcam du PC

      La caméra exige une connexion sécurisée. Sur le PC, lancez miroir webcam et scannez le nouveau code QR.

      Avertissement de sécurité à chaque fois ? Installez l'autorité Miroir sur ce téléphone (voir le README).

      Envoyer une notification au PC

      Notifications du bureau indisponibles : installez libnotify-bin sur le PC (elles s'affichent quand même dans le terminal).

      Transférer toutes les notifications du téléphone

      Une page web ne peut pas lire les notifications d'Android. Créez une macro dans une appli d'automatisation (MacroDroid, Tasker, Automate…) :

      1. Déclencheur : Notification reçue (toutes les applis, ou celles choisies).
      2. Action : Requête HTTP POST vers l'adresse ci-dessous.
      3. Corps (JSON) : {"appli":"[app_name]","titre":"[notification_title]","texte":"[notification]"}

      Cette adresse contient votre clé secrète : ne la partagez pas.
